## MoonShine Spring

The `5.x` branch requires PHP 8.4+ and MoonShine `5.x-dev`. Use the `4.x` branch for MoonShine 4.

### Install

1. Install the package via Composer:
    ```shell
    composer require moonshine/spring:5.x-dev moonshine/moonshine:5.x-dev
    ```
2. Run the command:
    ```shell
    php artisan moonshine-spring:install
    ```
